## 🌟 How funds are used

All sponsorship is used transparently for:
1. **Infrastructure** — server operations, domain renewal, CI/CD compute;
2. **Testing and development hardware** — cross-platform debugging devices, load and performance benchmark environments;
3. **Open-source ecosystem upkeep** — documentation translation, community tooling and workflow automation;
4. **The author's coffee** ☕ — incentive for more high-quality output.
